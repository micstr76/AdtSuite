AdtSuite

Application & Deployment Tool Suite

WPF-Desktop-Anwendung zum Generieren von PowerShell-Installations­scripts für SCCM/MECM-Software-Distribution — mit Live-Mermaid-Vorschau, automatischer Doku-Generierung und vollständiger MECM-Integration.

⚠ Beta-Version 1.0.0: Funktionen können sich noch ändern. Bug-Reports bitte über den Fehler melden-Dialog in der App.
⬇ Neueste Version herunterladen 🐞 Bug oder Feature melden

Was kann AdtSuite?

Generiert produktionsreife PowerShell-Scripts für SCCM-Application-Deployments — mit allem was eine moderne Paketierungs-Pipeline braucht.

📜

PowerShell-Generator

Install-/Uninstall-Scripts mit Pre-Checks, Logging, Pending-Reboot-Detection und Branch-Logic (if/elseif/else) — alles SCCM-ready.

🎯

MECM-Integration

Direkte Verbindung zur ConfigMgr AdminService REST-API. Detection-Methods, Requirements und Deployment-Types per UI konfigurieren.

📊

Mermaid Live-Flow

Visualisierung der Skript-Logik in Echtzeit mit drei Detail-Levels (Übersicht / Details / Voll). Export als Markdown oder HTML.

📚

Automatische Doku

Generiert lesbare Dokumentation für Script und MECM-Anwendung — zur Übergabe an Service-Desk oder Audit-Stellen.

🧩

Snippet-Library

Wiederverwendbare Code-Bausteine mit zentraler UNC-Source, ZIP-Export/Import und Vorlagen pro Kategorie.

🌗

Modern + Classic UI

Zwei vollwertige Oberflächen: schlankes Dark-Gold-Modern oder klassisches Layout mit drei Farbschemata.

🌍

Mehrsprachig

Vollständige DE/EN-Lokalisierung mit Live-Umschaltung — kein Neustart, keine RESX-Kompilierung.

🔄

Auto-Update-Check

Beim Start und auf Klick prüft die App ob eine neue Version verfügbar ist — ohne Self-Updater, alles transparent über Browser.

Tech-Stack

Modern, gut wartbar, ohne Legacy-Ballast.

.NET 9 WPF MVVM C# 13 AvalonEdit WebView2 Markdig Mermaid.js ConfigMgr REST-API PowerShell 5.1 / 7.x
